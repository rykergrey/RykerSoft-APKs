# RykerSoft Public Distribution

This repository contains the reviewed current Android and Windows release artifacts and hub documentation referenced by the RykerSoft Application Manager.

- Downloads and documentation are intentionally public and anonymously accessible.
- Application source code may live in separate private repositories.
- No GitHub personal access token is required or accepted by the Android client.
- Public binaries do not grant Pro access. Pro capabilities are authorized separately by package-specific Firebase UID entitlements.
- Release artifacts are published as GitHub Release assets rather than committed to this repository.

The previous private distribution history is retained separately as a private archive and is not part of this public repository.
