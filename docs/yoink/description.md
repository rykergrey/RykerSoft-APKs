# yoink.

Download a video, make it yours, and keep the whole story in one place. yoink. combines a focused yt-dlp downloader, a non-destructive FFmpeg studio, and an optional assistant in one desktop workspace.

## Key Features

- Download video or audio with practical presets and detailed codec, quality, subtitle, metadata, and transfer controls.
- Inspect streams, chapters, tags, color properties, side data, and other technical file metadata.
- Trim, split, join, normalize, replace audio, manage tracks, edit metadata, and export new versions without changing the original.
- Keep downloads, edits, assistant requests, answers, and exports together in a chronological media profile.
- Use OpenAI or Gemini with personal API keys held only in native memory, or connect the installed Codex CLI with an eligible ChatGPT plan.
- Run on Windows or Linux. The installed media engines remain under the user's control.

## PRO Features

Items marked * require administrator-granted Yoink Pro access for the signed-in RykerSoft account. Sign in to the same Google account inside yoink.; personal API keys remain an independent alternative and take priority.

* **Managed OpenAI access** — Use the administrator-configured OpenAI credential for assistant planning, questions, and supported transcription.
* **Managed Gemini access** — Use the administrator-configured Gemini credential for assistant planning, questions, sampled-frame analysis, and explicitly approved video analysis.
* **Managed Groq transcription** — Use the administrator-configured Groq credential for Whisper transcription.

Downloads, file inspection, manual editing, exports, browser preview, personal provider keys, and the optional Codex CLI connection remain available without Pro access.

## Requirements

- Windows 10/11 x64 or a contemporary x86_64 Linux distribution.
- `yt-dlp`, `ffmpeg`, and `ffprobe` available on `PATH`.
- Internet access for downloads, provider requests, and RykerSoft sign-in.
