# Umm specifications

| Item | Behavior |
| --- | --- |
| Release | 0.5.1 — November 14, 2026 |
| Android package | com.oddly.app.release |
| Android version code | 11 |
| Minimum Android | Android 6.0 / API 23 |
| On-device dictation | Android 12 / API 31 or later, supported recognition service and installed language required |
| Question formats | Multiple choice, true/false, fill in the blank, open text, bullet/numbered lists |
| Lists | Up to 30 items, 200 characters per item; Enter adds, drag/keyboard reorders |
| Creation | Single question first; adding another makes a quiz, up to 20 questions |
| Timers | No timer, or 15–600 seconds |
| Answer updates | Creator chooses add-only or final; legacy cards retain their existing policy |
| Mystery pool | Fresh player-made questions first, then ready-made cards; generated reserve replenishes in background |
| Audio | Piano/celesta interface effects with persistent mute and volume |
| Accounts | Umm Google account for gameplay; separate RykerSoft account for Pro creator tools |

On-device speech uses Android’s explicit offline recognizer and never uploads audio through Umm. Permission denial, missing services and unavailable languages leave typed input available. Browser dictation still depends on an unconfigured Groq service. The hosted AI service supports drafting, remixing and palette prompts; creator AI requires a verified Pro entitlement. Questions and answers are not scored for correctness. Coins are earned/spent in the game and cannot be purchased for money.
