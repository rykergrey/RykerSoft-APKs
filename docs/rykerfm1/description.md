# RykerFM1

RykerFM1 is for people who own an M-Vave FM-1 and run community firmware on it. It has two places.

**The Library** shows every firmware on [The Firmware Hub](https://thefirmwarehub.com), with its maker's picture and words. Browse it as a shelf of pictures or a dense index, search it, narrow it by type, style and sound engine, and open a page for any firmware: what it is, which FM-1s it runs on, its release notes, and links to its repository, site, browser emulator and editor.

**The Bench** installs a firmware on the FM-1 over a USB-C cable, straight from the phone. It reads which firmware the unit is running, checks the package before writing, and tells you exactly where a failure happened.

What you keep stays on your phone: favourites, pins, a watch list that flags new versions, your own star ratings, lists you name and notes. Nothing is sent anywhere, and all of it exports to one file.

## Features

- Every firmware on The Firmware Hub, as pictures or a dense index
- Search, filters and the hub's orders: most installed, top rated, recently updated
- Install over USB from the phone, with the package checked first
- A watch list and a daily check that tells you when a firmware has a new version
- An install history, and one tap to put back the firmware you had before
- Favourites, pins, ratings, lists and notes that stay on the phone
- Keep a package on the phone to install without a connection

RykerFM1 is free. It has no account and no Pro features.

The firmware list is The Firmware Hub's catalog (CC BY 4.0). Each firmware belongs to its maker.
