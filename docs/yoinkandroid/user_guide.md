# Getting started

1. Download the Android APK from RykerSoft and install it, allowing installation from RykerSoft when Android prompts.
2. Paste a media link to download, or import a file into Studio.
3. Select a source track or clip, adjust trim points or effects, and create a new version. Studio autosaves the current session before you leave; reopening the video restores it. Export files through the system picker.
4. Add personal provider keys in AI settings for optional assistant features; review the estimate before each paid request.

On the home screen, use the title bar filter button for download status, media type, and sort order. Open a completed video to focus on it alone. Its three-dot menu contains Media details, Clip history, and Close video.

Android exports run in a persisted foreground queue and can continue after leaving the editor. Keep the app open during long downloads and assistant operations. Keys need to be re-entered after the app process stops. Export important files before removing the app: downloads and edit histories live in app-private storage.

## Existing development installations

The public release is signed with the RykerSoft release key. Earlier debug builds use a different certificate and cannot be upgraded in place. Keep your existing installation until you have exported important media; uninstalling clears its local data. This publication does not remove or alter the development app installed on your phone.
