# yoink. for Android

Download video or audio and edit it in a non-destructive media workspace. Studio now autosaves independent editing sessions, offers cached proxy previews for smoother seeking, and keeps Android export batches in a persisted foreground queue. The library shows export progress and controls.

Downloads, manual editing and exports are available without a subscription. Optional OpenAI, Gemini and Groq features use your personal API keys, kept in memory for the app session. Desktop RykerSoft Pro sign-in and Codex connection are not available on Android.
