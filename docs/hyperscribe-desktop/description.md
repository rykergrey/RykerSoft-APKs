# Hyperscribe Desktop

Hyperscribe Desktop is a local-first voice, text, action, chat, and speech workspace for Windows. Capture clipboard text or audio, organize an Inbox, transform content with reusable actions and pipelines, chat with configurable AI providers, and read content aloud with local or cloud speech.

## Features

- Record, import, transcribe, edit, tag, search, share, and back up voice and text items.
- Build AI, Python, template, snippet, search, persona, TTS, and combo actions.
- Keep persistent chat threads with streaming, editing, regeneration, action context, and TTS.
- Use Piper locally, Windows speech where available, or configure Gemini and ElevenLabs speech.
- Keep provider credentials in local application settings and out of backups and release artifacts.
- Move action libraries between Android and Windows using compatible JSON exports.

## Platforms

- Windows 10/11 on x86-64.
- Portable PyInstaller executable; no Python installation required.

## PRO Features

Hyperscribe Desktop v2.2.0 does not gate features behind RykerSoft Pro access. Cloud features use bring-your-own provider credentials, while recording, organization, local actions, and local TTS remain usable without a RykerSoft account.

## Privacy

Content is stored locally unless the user explicitly invokes a configured cloud provider or shares/exports it. Provider credentials are excluded from backups, diagnostics, source control, and release artifacts.
