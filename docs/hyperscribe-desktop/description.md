# Hyperscribe Desktop

Hyperscribe Desktop is a local-first voice, text, action, chat, and speech workspace for Windows and Linux. Capture clipboard text or audio, organize an Inbox, transform content with reusable actions and pipelines, chat with configurable AI providers, and read content aloud with local or cloud speech.

## Features

- Record, import, transcribe, edit, tag, search, share, and back up voice and text items.
- Build AI, Python, template, snippet, search, persona, TTS, and combo actions.
- Keep persistent chat threads with streaming, editing, regeneration, action context, and TTS.
- Use Piper locally, Windows speech where available, or configure Gemini and ElevenLabs speech.
- Use personal provider keys or connect approved RykerSoft Pro access with Google. Provider keys are excluded from backups and release artifacts.
- Move action libraries between Android and Windows using compatible JSON exports.

## Platforms

- Windows 10/11 and Linux on x86-64.
- Portable PyInstaller executable; no Python installation required.

## PRO Features

RykerSoft Pro provides shared Gemini, OpenAI, Groq, and ElevenLabs access plus cross-device synchronization. Approved family and friends connect with the same Google account used for RykerSoft. Other users can enter their own provider keys; recording, organization, local actions, chat with personal keys, and local TTS remain available without Pro.

## Privacy

Content is stored locally unless the user explicitly invokes a configured cloud provider or enables Pro cloud sync or shares/exports it. Provider credentials are excluded from backups, diagnostics, source control, and release artifacts.
