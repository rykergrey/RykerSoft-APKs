# Updates

## 1.1.1 — September 10, 2026
- Fixed clipped menus on narrow screens.
- Tap images and captions to edit; drag or swipe to browse versions.
- Caption history preserves wording and fonts, including in editable backups.
- Dedicated Download menus for panels and comics.
- Compact header with a session export icon and no routine saved-status bar.
- Account/Pro access is now at the bottom of Home.

## 1.1.0 — September 9, 2026
- New Windows portable and Linux AppImage/archive releases.
- Idea-first creation with text-based styles and optional fine-tuning.
- Comic-first workbench, draft autosave, and background work during in-app navigation.
- Individual artwork retry and safer concurrent caption/image editing.
- Explicit editing menus, persistent deletion recovery, and Trash.
- Library search, sorting, session naming, and simpler export choices.
- Improved mobile layout and accessible editing dialogs.
- Desktop Google sign-in through the system browser using your RykerSoft account.

## 1.0.0 — September 7, 2026
- First signed Android release for RykerSoft.
- Google sign-in and per-app Pro access for AI creation tools.
- Native Android sharing for pictures, strips, and ZIP backups.
- Bundled styles and fonts for consistent offline appearance.
- Smaller mobile home layout, accessible session cards, touch targets, keyboard focus, and reduced-motion support.
- New first-comic guide and visible account controls.
- Clearer generation progress and failures; duplicate generation is disabled while a comic is being created.
- Storage writes wait for transaction completion.
- Runtime Gemini key delivery replaces build-time provider key injection.
