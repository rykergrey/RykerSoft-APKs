# ComicCraft.ing

Turn a premise, joke, or reference image into a comic, then shape the result panel by panel. Bold lettering, halftone backgrounds, and expressive art styles make the workbench feel like a comic studio.

## Features
- Browse saved sessions on your device.
- Edit caption text and fonts by hand.
- Duplicate, reorder, and remove panels.
- Share artwork, captioned panels, and comic strips.
- Export and import editable ZIP backups.

## PRO Features
Items marked * require ComicCraft.ing Pro access for your RykerSoft account. Sign in with the same Google account you use in RykerSoft.

* **Comic generation** — Write a script and illustrate it from an idea or reference image.
* **Visual transformations** — Describe changes to your artwork.
* **Related panels** — Extend an existing scene with a new panel.
* **Caption enhancement** — Rewrite a caption with your selected style and tone.

Saved comics and manual editing work without Pro access. AI features require internet access and a configured Gemini service. Your comics are stored locally; export backups before uninstalling or clearing app data.
