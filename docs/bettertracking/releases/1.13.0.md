# Better Tracking 1.13.0

October 20, 2026 · Android versionCode 28

Adds an Index Assistant `staging_item` capability backed by the actual Better Tracking staging tray. A reviewed “100 g Chicken Breast” can use an existing library item and save its quantity, unit, date and custom values to the tray without creating a library item or a journal entry. Durable stage records and receipts commit atomically in the current owner's cloud store, including deterministic combo expansion.

The tray merges these stages with manual selections, restores them after restart and clears the former owner's records on account changes. Native quantity edits and removal compare revisions. Logging selected stages saves journal entries and removes those exact stages in one transaction, with deterministic IDs to prevent duplicate retry saves. The visible tray remains protected from concurrent bridge writes. Bounded library search metadata and full reads now disclose each item's supported `validUnits`.

Local regression checks cover stage validation, item revisions, retry identity, lost acknowledgement recovery, atomic failure, combo expansion, native stage edit/remove/log transactions, manual-stage coexistence and account replacement. Exact build artifacts and checks are recorded separately. No physical verification is claimed by this document before installation.
