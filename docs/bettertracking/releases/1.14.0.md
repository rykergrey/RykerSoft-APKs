# Better Tracking 1.14.0

October 26, 2026 · Android versionCode 30

Keeps the calorie difference from all locally available usable prior food days visible until later logged days balance it. The full-history allowance can be negative and is explicitly accounting, separate from the daily goal and optional guidance. Missing, skipped, excluded and incomplete days do not create unused allowance. Backdated changes recalculate subsequent balances.

Daily and recent views compare intake with both base goals and estimated maintenance. Optional recent-window plans and automatic calorie pacing use daily adjustment caps, nutrient-aware lower bounds and calorie limits. Plans can leave historical balances rather than forcing an exact repayment deadline. Conflicting nutrient/calorie goals withhold suggestions. Fixed calorie overrides remain fixed and automatic pacing stays off by default.

Daily nutrient goals retain their meaning. Earlier extra fat, protein or other nutrients do not reduce today's goals; earlier low sodium does not increase today's limit. Nutrient history remains visible separately. Historical goals are reconstructed from current profile settings and available dated weight, since historical profile versions are not stored. See [rolling goal balances](../rolling-goal-balances.md) for calculations and coverage rules.

This public release also includes the optional default-off Android [Index Assistant connection](../index-assistant-bridge.md), including owned library/journal reads and validated edits, durable staging, and explicit read-only metadata for ordinary volatile tray selections. Save or log unsaved manual selections before restarting or updating the app.

Available as a production-signed Android APK, Windows x64 portable EXE, Linux x64 AppImage and Debian package. Windows executables are not Authenticode signed. Exact package metadata, signer, hashes, source revision and public verification are recorded with the release artifacts. Physical-device, native UI and live AI/provider checks are reported separately when performed.
