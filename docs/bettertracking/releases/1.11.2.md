# bettertracking 1.11.2

October 14, 2026 · Android versionCode 25

Home’s upper-right Log/Stats control now separates daily logging from period statistics. Log shows the selected day’s dashboard and entries with a daily date navigator. Stats opens Week the first time and retains the chosen range when you return. One range control in Stats offers Day, Week, Month, Year, All time and Custom and applies to both of its tabs.

Trends & History keeps charts, calculated metrics, relationships, food exploration and selected-period log history together. Analysis contains inline AI reviews, saved reports, exports and chat follow-ups for those same dates. Nutrition and confirmed weight goals remain the first emphasis. A date opened from statistics returns to that day in Log.

Available packages: signed Android APK, Windows x64 portable EXE, Linux x64 AppImage and Debian package. The Windows portable build is not Authenticode signed. Statistics and data exports are calculated locally; in-app AI generation uses configured provider credentials. No new backend migration is required.
