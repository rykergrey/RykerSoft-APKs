# Better Tracking 1.12.0

October 20, 2026 · Android versionCode 26

Adds the optional [Index Assistant connection](../index-assistant-bridge.md) on Android. Library items and dated journal content support owned, bounded read/search and validated create/update with exact revisions and atomic confirmed save receipts. Separate native read/write grants default off. Profile/health-goal settings, credentials, tokens and deletion are excluded.

Creates are deterministic for each accepted owner/request identity. Interrupted claimed work reconciles the canonical Firestore receipt instead of replaying. Existing editors/staged content, owner changes, revocation, cancellation and expired requests prevent uncommitted changes. Existing rich/media/unknown fields outside requested changes are retained.

Release artifacts and verification are recorded locally during packaging. This note does not claim a phone installation or external publication.
