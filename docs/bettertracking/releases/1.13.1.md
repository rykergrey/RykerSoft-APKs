# Better Tracking 1.13.1

October 20, 2026 · Android versionCode 29

Completes Index Assistant staging-tray reads by including ordinary manual selections from the owning runtime alongside durable bridge-created stages. Manual rows have stable `manual:<trayKey>` identities, content revisions and explicit local/volatile/read-only metadata. Search with an empty query lists the entire tray; filtered results disclose both matched and unfiltered counts. Exact reads retain item identity, quantity, unit, custom values and the tray's effective date.

Reading the tray does not migrate, save, log, remove or duplicate manual selections. Bridge updates against manual IDs return an explicit unsupported-operation result directing the user to Better Tracking. Canonical stages keep their existing durable receipt and transaction semantics. Existing manual tray persistence behavior is unchanged: a terminated process can lose its unsaved selections, so preserve those selections before installing an update.

Regression checks cover merged manual/durable reads, identity deduplication, per-item availability, exact revisions, literal name/date/domain filtering, and absence of write transactions or receipts for manual reads. Physical verification and exact signed artifacts are recorded separately.
