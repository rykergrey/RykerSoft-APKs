# Pocket DM

Invent an improbable character, pass the phone, and turn your next move into a narrated comic. Pocket DM is a two-player storytelling game on one Android device: freeform ideas drive the encounter, while the local game service keeps turns and consequences bounded.

- Describe a character’s identity, personality, and appearance. Character creation runs in the background while the other player enters an idea.
- Meet player A, then player B through scrolling introductions, with each original portrait appearing last.
- Speak or type an attempted tactic. Read the comic before revealing the accepted consequences.
- Keep a character’s secret private during setup, then freeze the accepted identity for the encounter.
- Use optional spoken commentary from offline Piper or your own OpenAI/ElevenLabs account.
- Resume local saved encounters and reuse each character’s artwork.

Version 0.2.7 reduces repeated portrait loading, moves binary decoding away from the visible Android interface, and reduces rendering work during reveals. Physical-device performance of this update is still awaiting verification.

## Connection and provider keys

Practice, basic character creation, and the bundled Piper voice work offline. Fresh installations start with an empty roster. Live interpretation and original portraits require OpenAI access; offline characters use a portrait placeholder. Live DM, original custom portraits, and cloud commentary need internet and a personal provider key entered in Settings. Provider usage may incur charges on that account. No starter fighters, shared provider key, or RykerSoft Pro service is included. New portraits use Pocket DM’s specific painterly art direction inspired by TF2: decisive silhouettes, simplified form, expressive gesture, controlled brushwork, warm highlights, and cool shadows. Google sign-in, remote multiplayer, cloud saves, and long-term progression are not implemented.

This is an early local prototype. Practice interpretation is limited; live storytelling can misunderstand choreography. Guest-seat handoffs provide practical privacy on a shared phone, rather than separate authenticated player accounts.
