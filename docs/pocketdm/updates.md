# Pocket DM updates

## 0.2.7 — October 12, 2026

First public RykerSoft release, using a dedicated production signer.

- Remove the default fighter roster, bundled starter portraits, and automatic sample matches.
- Give new original portraits a detailed TF2-inspired painterly art bible with a versioned cache policy.
- Share original portrait loads and image URLs across cards and comic panels.
- Decode Android binary replies off the main UI thread; send small one-use file tickets to the interface instead of large base64 scripts.
- Mount only the comic scene being read on phones.
- Reduce Android background shader work and remove expensive portrait filters/intro blur while preserving reveal motion.
- Retain caption controls, private handoffs, saved pending comics, and duplicate-safe consequences.

All 241 source tests pass. Fifteen deterministic scenarios and 90 replay-checked synthetic duels pass. Physical-device performance of this correction remains unmeasured. Earlier debug installs cannot update directly to the new production signer; remove the earlier debug build before installing this public release, which erases its local data.
