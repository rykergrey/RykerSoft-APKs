# Field Recorder

Field Recorder is a shared-device category word game for 2–8 players. Gather around the retro console, read the letter and category, then hold the microphone button and speak an answer. Release to submit and keep the game moving while transcription finishes in the background.

- Timed and round-based matches with configurable players and category packs.
- Push-to-talk audio recording, spoken custom deck questions, and post-game audio replay.
- Editable transcripts and scores for player review.
- Saved player rosters, custom decks, and match history on the device.
- Android speech transcription using your own Groq key or Field Recorder Pro access, with no computer connection required.

## PRO Features

* **Transcription without a personal API key** — Sign in with the same Google account you use in RykerSoft and enable Field Recorder Pro access for that account. The app uses the administrator-configured Groq service for game answers and spoken deck questions.

Recording, gameplay, deck editing, and match review remain available without a RykerSoft account. You can always enter your own Groq key; a saved personal key takes priority over the Pro service, and its usage is charged to your provider account. Both transcription paths need an internet connection. Optional Gemini judging and generated deck ideas require a separately configured API server; that server is not bundled in the APK.
